# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
100% Static Web Architecture (HTML/CSS/JS) deployed via GitHub Pages.

## Users
Tech Recruiters, Engineering Managers, and Tech Leads. Their goal is to quickly evaluate technical experience, analyze code quality from real projects, understand problem-solving capabilities, and download the resume for a potential interview.

## Product Purpose
To showcase fullstack and infrastructure engineering expertise alongside high-end frontend polish. It acts as a visual evolution that takes a solid, proven foundation and elevates it with premium UI/UX, proving that structure and stunning visual design can coexist.

## Positioning
FullStack Developer focused on React, Tailwind CSS, and Docker, with specialized expertise in deploying, maintaining, and optimizing geospatial systems using container orchestration and cloud infrastructure. The portfolio's unique angle is its fusion of heavy structural engineering with a "wow" factor through 3D animations and modern design trends.

## Operating Context
Accessed via web browsers (often rapidly scanned) by technical leadership and recruiters evaluating candidate portfolios.

## Capabilities and Constraints
- **Strictly Static**: Must be completely static HTML, CSS, and client-side JavaScript. No server-side rendering, Node.js backend, or internal API routes.
- **GitHub Pages Hosting**: Must be 100% compatible with GitHub Pages constraints (including 1GB limit, base URL paths, and client-side routing fallbacks).

## Brand Commitments
- Must preserve the existing general color palette.
- Must preserve the current overall layout and structural organization.

## Evidence on Hand
- Existing portfolio projects (content, descriptions, and links).

## Product Principles
- **Engineering Meets Aesthetics:** Build visually stunning interfaces without sacrificing structure.
- **Premium Micro-interactions:** Use modern UI/UX and 3D animations to create a memorable, cutting-edge experience.
- **Static and Fast:** Keep performance high and adhere strictly to the static-site constraints.
